# HTTP Monitor

WPF-приложение для мониторинга HTTP-запросов с использованием **HttpClient** и **HttpListener**.

---

## Возможности

### HTTP-Сервер
- Встроенный HTTP-сервер на базе `HttpListener` с настраиваемым портом
- **GET-запросы** — возвращает JSON со статусом сервера: количество обработанных запросов, время работы, среднее время обработки
- **POST-запросы** — принимает JSON (`{"message": "текст"}`), сохраняет в коллекцию и возвращает уникальный идентификатор
- Многопоточная обработка входящих запросов
- Валидация входных данных с корректными HTTP-кодами ошибок (400, 405, 500)

### HTTP-Клиент
- Отправка **GET** и **POST** запросов на любые URL
- Поддержка JSON-тела для POST-запросов
- Отображение полного ответа: статус, заголовки, тело, время выполнения
- Автоматическое форматирование JSON в ответе

### Мониторинг и аналитика
- Статистика в реальном времени: счетчики GET/POST, среднее время обработки, аптайм
- График пиковой нагрузки (по минутам / по часам) на базе **LiveCharts**
- Таблица всех запросов с сортировкой
- Фильтрация логов по методу (GET/POST) и коду ответа (200, 400, 404, 500)

### Логирование
- Логи в реальном времени в текстовом поле (метод, URL, заголовки, тело)
- Автоматическая запись в файл `logs_<port>.txt`
- Экспорт логов через диалог сохранения

---

## Технологии

| Компонент | Технология |
|-----------|-----------|
| UI | WPF (.NET 8) |
| HTTP-сервер | `System.Net.HttpListener` |
| HTTP-клиент | `System.Net.Http.HttpClient` |
| Графики | LiveChartsCore (SkiaSharp) |
| JSON | Newtonsoft.Json |

---

## Запуск

```bash
cd HttpMonitor
dotnet run
```

> Для работы сервера на Windows может потребоваться запуск от имени администратора.

## Интерфейс

### Вкладка «Сервер»
- Поле ввода порта и кнопка запуска/остановки
- Индикатор состояния сервера
- Панель статистики (GET, POST, всего, среднее время, аптайм)
- Логи с фильтрацией и кнопками очистки/сохранения

### Вкладка «Клиент»
- Поле URL, выбор метода GET/POST
- Поле для JSON-тела запроса
- Область отображения ответа

### Вкладка «Мониторинг»
- График нагрузки с переключением интервала (минуты/часы)
- Таблица запросов: время, метод, URL, статус, длительность
